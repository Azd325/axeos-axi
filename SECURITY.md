# Security policy

## Supported versions

Security fixes are applied to the latest released version; see [RELEASING.md](RELEASING.md).

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, especially one involving miner access or the handling of pool settings. Report it privately through [GitHub's repository security advisory form](https://github.com/Azd325/axeos-axi/security/advisories/new).

Include the affected version, a minimal reproduction, impact, and any relevant redacted logs. Do not include miner addresses, hostnames, MAC addresses, Wi-Fi names, pool users, payout addresses, or unredacted API responses.

You will receive an acknowledgement within 7 days. After a fix is available, disclosure will be coordinated with the reporter.
